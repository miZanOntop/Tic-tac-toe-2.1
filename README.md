# MIJAN ARENA — TIC TAC TOE

A cinematic, space-inspired Tic Tac Toe game built with vanilla HTML, CSS and JavaScript.

## Play

Once GitHub Pages is enabled, visit:

https://miZanOntop.github.io/Tic-tac-toe-2.1/

## Features

- Local two-player mode
- Play against the computer with Easy, Medium and Impossible difficulty
- Score tracking for X, O and draws
- Rematch and new-round controls
- Original synthesized sound effects and ambient music (start music with the MUSIC button)
- Responsive layout for desktop and mobile
- Animated starfield and space-inspired arena

## Run locally

Open `index.html` in a modern browser. No build tools or dependencies are required.

## Publish with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to finish publishing. The public URL is shown in the Pages settings.

## Controls

- **M** — toggle ambient music
- **S** — toggle sound effects
- **Esc** — close the result overlay

Sound is generated in the browser and starts only after a user interaction, as required by browser autoplay rules.
